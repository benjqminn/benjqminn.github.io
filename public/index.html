ResearchGraduate project

Forensic Visibility in AWS

I built a controlled AWS environment to test how well its logs could reconstruct simulated attacker activity. The work involved collecting evidence, checking hashes, and piecing together timelines across multiple logging sources.

I wanted to understand what you can recover from those logs, where the gaps are, and how much changes when you correlate the sources.

  1. 01Simulate activityControlled AWS environment
  2. 02Collect evidenceCorrelate native log sources
  3. 03ReconstructCheck hashes & build timelines

Obscura

A SOC simulation I built to work with packet captures. It parses uploaded PCAP files, checks for SYN scans, brute-force activity, and YARA matches, and displays alerts in a React dashboard.

I worked on both the Python analysis backend and the interface for reviewing its output.

About me

I like building something, seeing how it behaves, and figuring out what I missed. That’s taken me from PCAP analysis and CTFs to cloud infrastructure and digital forensics research.

I’m interested in cloud security, identity and access management, SOC work, and security engineering. I’m also exploring how AI fits into security and the systems we build.

At UNC Charlotte, I’m the Cloud Programs & Events Lead for the AWS Cloud Club and an officer in the 49th Security Division. I help organize workshops and labs, and compete in CTFs with the club.

Outside of tech, I’m an aspiring bodybuilder. It’s a long-term ambition I’m pursuing alongside graduate school and my career.
